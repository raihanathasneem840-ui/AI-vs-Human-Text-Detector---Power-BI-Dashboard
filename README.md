# Project 1: Power BI Dashboard

## 📊 Project Overview

An interactive Power BI dashboard created to transform raw business data into clear, actionable insights through data cleaning, analysis, KPI tracking, and visualization.

## 🎯 Project Objective

The objective of this project is to analyze business data and present important performance indicators in an interactive dashboard that supports data-driven decision-making.

## 🛠️ Tools & Technologies

- **Power BI**
- **Power Query**
- **DAX**
- **Microsoft Excel**
- Data cleaning and transformation
- Data visualization
- KPI analysis
- Dashboard development

## 🔍 Key Work Performed

- Imported and prepared raw data for analysis.
- Cleaned and transformed data using Power Query.
- Handled data quality issues such as missing values and inconsistencies.
- Created calculated measures using DAX.
- Developed interactive KPI visuals and charts.
- Designed an easy-to-use dashboard for exploring business performance.
- Presented trends and key metrics through visual reporting.

## 📈 Dashboard

The Power BI dashboard file is included in this repository:

**`Project_1_Power_BI_Dashboard.pbix`**

> Open the `.pbix` file using Microsoft Power BI Desktop to explore the interactive dashboard.
